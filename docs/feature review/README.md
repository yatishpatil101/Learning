## How to use these

1. Read `01` first — it frames *why* the plain "verify everyone" idea is risky on the core market.
2. Read `02` — it shows the **one segment (flat-share) where the KYC obsession becomes an asset**, and how to go to market.
3. Each doc ends with a **verdict + the single biggest risk to de-risk first** and an
   **implementation checklist** you can lift into `tasks/todo.md`.
